Connecting to UoB Maths servers from a Linux box

Assembled by Márton Balázs, IT rep for Maths
last updated: [2025-07-10]


 

Please note, your local Linux machine is not backed up by IT, hence the importance of connecting to UoB servers. The NSF mapping of Heilbronn homes to e.maths below is no longer in place after our move to Fry.

Throughout, [username] is your UoB username in the format ab12345. Here is a summary about servers that might need to be reached (Cream, Blue Pebble or Blue Crystal are not covered, but should work very similarly):

  • Microsoft's OneDrive, accessible via a web browser interface from Linux. One can also connect via rclone, please see here.
  • seis.bris.ac.uk, the University Linux bastion server and UoB homepage server. UPDATE as of the 10th July, 2025: this server is now also put behind VPN from outside Campus, which kind of beats the bastion server role. It accepts interactive ssh connection, and a webpage put in its 
    /home/[username]/public_html/
    folder can be publicly accessed as http://seis.bris.ac.uk/~username/.
  • personal-webpages.maths.bris.ac.uk, the Maths homepage server. It can only be connected from the internal UoB network (or via VPN). A webpage put in its 
    /home/[username]/public_html/
    folder can be publicly accessed as http://www.maths.bris.ac.uk/~username/.
  • e.maths.bris.ac.uk, the Linux Maths personal storage space, backed up. It used to work through scp, sshfs, rsync,... and smb, cifs only, but it now also accepts interactive sessions through ssh login.

These servers can be accessed via smb and cifs, see some of this here or here. However, smb seems to mess up Linux file permissions, while cifs asks for sudo rights and can be a drawback with synchronisation tools like rsync. Hence this little page is to describe access to the last three of the above servers via ssh, scp, sshfs, rsync.

The server seis could be accessed from both inside and outside the University in the usual secure ways until the 10th July, 2025: 

ssh -X [username]@seis.bris.ac.uk
 
sshfs [username]@seis.bris.ac.uk:/home/[username]/ ~/local_mount_point/
 
scp [file] [username]@seis.bris.ac.uk:/home/[username]
 
rsync -[options] -e ssh [local dir]/ [username]@seis.bris.ac.uk:/home/[username]/[remote dir]/
or fish (as the Shell link in mc). An sshfs session should be terminated by 
fusermount -u ~/local_mount_point/
after usage as lost connections can result in pausing the local filesystem. From the 10th July, 2025, seis is put behind VPN from outside Campus.

Access to the servers personal-webpages and e is done in a similar way from within the UoB network. I personally use rsync in my startup and bye-bye scripts to publish my webpage on personal-webpages and back up other files to e, see more about this here.

From outside the UoB network, one can use either VPN (here is a version for students connecting from China) after which there is no need for what's below here, or seis to build an ssh tunnel to personal-webpages and e in the following way. On your local machine, create or add to the file 

~/.ssh/config
the following lines: 
Host personal-webpages.maths.bris.ac.uk
	User [username]
	ProxyCommand ssh [username]@seis.bris.ac.uk nc personal-webpages.maths.bris.ac.uk 22

Host e.maths.bris.ac.uk
	User [username]
	ProxyCommand ssh [username]@seis.bris.ac.uk nc e.maths.bris.ac.uk 22
Once this is done, everything works as usual (except password is asked twice, once by seis and then by personal-webpages or e). E.g., 
sshfs [username]@personal-webpages.maths.bris.ac.uk:/home/[username]/ ~/local_mount_point/

An alternative to ProxyCommand is ProxyJump, see e.g., here.

In all of the above you can use ssh keys, and possibly ssh-agent, to avoid entering your password several times. In this case a strong passphrase for ssh keys and a time limit on ssh-agent is strongly advised.
