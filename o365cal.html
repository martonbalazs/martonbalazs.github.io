Office 365 calendar saver for Linux


 

  1. Make sure you have wget installed.
  2. Create an empty directory.
  3. Open https://www.office.com/, log in, click Calendar, click the cogwheel upper right, then Calendar, then Calendar publishing on the left. Set it to Full details, and click Save. The url for your calendar.ics file should appear.
  4. Download the script, and edit its first few lines with the name of your empty directory and the url of your calendar.ics file.
  5. Run the script say, daily. You could even add it to crontab. Your saved calendars, compressed, will be in your directory.
